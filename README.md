# Customer Churn Analysis Dashboard

## 📌 Project Overview
The Customer Churn Analysis Dashboard is an interactive business intelligence solution developed using Power BI to analyze customer behavior, identify churn patterns, and generate actionable insights for improving customer retention strategies.

---

## 🎯 Objectives
- Analyze customer churn behavior and retention trends
- Identify high-risk customer segments
- Discover major factors driving customer attrition
- Provide data-driven insights for customer retention strategies

---

## 🛠️ Tools & Technologies Used
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

---

## 📊 Dashboard Features
- KPI Cards for Total Customers, Total Churn, New Joiners, and Churn Rate
- Churn Analysis by Contract Type
- Churn Analysis by Payment Method
- Churn Analysis by Internet Service
- State-wise Churn Analysis
- Age Group and Tenure Analysis
- Interactive Filters and Slicers
- Tooltip Pages for Detailed Churn Reason Analysis

---

## 🔍 Key Insights
- Identified a 27.0% customer churn rate across 6,418 customers.
- Month-to-Month contracts showed the highest churn rate (46.53%).
- Fiber Optic internet users had significantly higher churn compared to other services.
- Customers using mailed check payments and customers from Jammu & Kashmir showed high churn risk.
- Competitor-related reasons such as better devices and better offers were major churn drivers.
